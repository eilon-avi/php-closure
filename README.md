# php-closure
Closure is a cli tool written in python that can generate php filter chains for wrapping any file with an arbitrary prefix and suffix.

# Installation

Install **closure** directly from GitHub using `pip`:

```bash
pip install git+https://github.com/adambedui/php-closure.git
```

Alternatively, clone the repository and install it locally:

```bash
git clone https://github.com/adambedui/php-closure.git
cd php-closure
pip install .
```

# Usage

After installation, the CLI is available from your terminal:

```bash
closure --help
```
